# LuminaLib Frontend

This scaffold is a Next.js + TypeScript frontend configured for SSR, Tailwind CSS, React Query, and unit testing with Jest + React Testing Library.

Quick start:

1. cd frontend
2. npm install
3. npm run dev

Notes:
- Adjust `NEXT_PUBLIC_API_BASE_URL` to point to your backend.
- API calls go through `services/api.ts` and components use hooks in `services/hooks`.
